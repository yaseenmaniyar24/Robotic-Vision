# 🤖 Robotic Vision

A collection of Robotics Vision laboratory programs, experiments, projects, and implementations using **Python and OpenCV**.

This repository contains image processing, computer vision, object detection, segmentation, feature extraction, and robotics vision experiments with their source code, results, and explanations.

---

## 📚 Contents

| No. | Topic                    | Description                                    |
| --- | ------------------------ | ---------------------------------------------- |
| 01  | Image Basics             | Reading, displaying and saving images          |
| 02  | Image Transformations    | Translation, rotation, scaling and reflection  |
| 03  | Image Filtering          | Mean, Gaussian, Median and Bilateral filtering |
| 04  | Edge Detection           | Sobel, Laplacian and Canny edge detection      |
| 05  | Thresholding             | Binary and adaptive thresholding               |
| 06  | Image Segmentation       | Otsu, watershed and region segmentation        |
| 07  | Morphological Operations | Erosion, dilation, opening and closing         |
| 08  | Contour Detection        | Detecting and analyzing object boundaries      |
| 09  | Object Detection         | Detecting objects using computer vision        |
| 10  | Robotics Vision Project  | Complete application of robotic vision         |

## 🎯 Objectives

The main objectives of this repository are:

1. To understand the fundamentals of computer vision.
2. To implement image processing techniques using Python and OpenCV.
3. To study different image enhancement and filtering methods.
4. To understand edge detection and image segmentation.
5. To implement object detection techniques.
6. To apply computer vision concepts to robotics applications.
7. To maintain laboratory programs with code, outputs, and explanations.

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Robotic-Vision.git
```

Move into the repository:

```bash
cd Robotic-Vision
```

Install required libraries:

```bash
pip install -r requirements.txt
```

Run any Python program:

```bash
python code_filename.py
```
